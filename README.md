# Simple Data Filtering

## Description

This project demonstrates how to filter student records using Python.

## Objective

To learn how to filter data using lists, dictionaries, loops, and conditions.

## Tools Used

* Python
* Jupyter Notebook

## Features

* Stores student details such as name, age, marks, and department.
* Filters students who scored more than 75 marks.
* Filters students belonging to the CSE department.
* Filters students younger than 21 years.

## What I Learned

I learned how to store student information using dictionaries and filter records based on different conditions using Python.

## Conclusion

This project helped me understand the basics of data filtering and improve my Python programming skills.
